# Data contract

**Source.** USAID *Supply Chain Shipment Pricing Data*, catalog identifier `a3rc-nmf6`, accessed through the historical public record. The project’s retrieval script records the source route, UTC retrieval time, SHA-256 hash and byte count locally.

**Redistribution.** The raw CSV is excluded. The catalog metadata presents inconsistent license signals (CC BY-ND 4.0 link, CC-BY wording in rights, and `other-license-specified` in the catalog). Reuse requires independent license verification.

**Grain.** A record is treated as a shipment line for analysis. It is not assumed to equal an invoice, supplier contract, or enterprise purchase order.

**Scope.** Results describe the observed SCMS historical extract only. Dollar values are observed line-item values in the source, not audited organizational spend or a claim about current suppliers.
